# Security Policy

## Responsible use

Edit With My Voice is intended for authorized audio repair and post-production workflows. Do not use it to impersonate people, mislead audiences, bypass consent, or create fraudulent content.

## Reporting vulnerabilities

Please open a private security advisory on GitHub or contact the repository owner. Do not publish exploit details before a fix is available.

## Local data

The app stores uploaded and generated media in the local `workspace/` folder. This folder is ignored by Git and should not be committed or shared by accident.
